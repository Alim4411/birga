# БИРГА — онлайн-запись к местным мастерам

Демо-прототип сервиса записи к мастерам в Назрани, Магасе и Карабулаке.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Для кабинета специалиста откройте `specialist.html`.

Сборка, сервер и установка зависимостей не требуются.

## Возможности прототипа

- Каталог мастеров с поиском и фильтрами по категории, городу и цене.
- Запись с выбором услуги, даты и свободного времени.
- Учёт рабочих дней и занятых временных слотов.
- Только оплата банковской картой (демо-режим, без списания денег).
- Напоминания браузера за 1 час до записи и в день визита (при открытом сайте и разрешённых уведомлениях).
- Поиск записей клиента по номеру телефона и отмена записи.
- Кабинет специалиста: подтверждение, завершение и отмена записей.
- Редактирование услуг, цен, города, рабочих дней и пароля.
- Админ-панель: список специалистов, общая таблица записей и сброс демо-данных.
- Тёмная тема и адаптивная вёрстка.

## Важно: ограничения демо-версии

Это **клиентский прототип**, а не готовая безопасная платформа для реальных клиентов. Данные хранятся в `localStorage` конкретного браузера и устройства. Чтобы клиентская и мастерская страницы видели одни данные, их нужно открыть в одном браузере на одном устройстве.

Пароли находятся в JavaScript и предназначены только для демонстрации. Не используйте реальные пароли и персональные данные. Демо-оплата картой не списывает деньги. Напоминания в этой версии работают, пока сайт открыт в браузере и браузеру разрешены уведомления; если сайт закрыт, браузер/устройство выключены или вкладка не запускается, уведомление может не прийти. Для гарантированных уведомлений по расписанию нужен сервер и push-уведомления. Для публичного запуска потребуются сервер, база данных, серверная авторизация, безопасное хранение паролей, резервное копирование и подключение платёжного провайдера.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `birga`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через несколько минут сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/birga/`.

Файлы `index.html`, `specialist.html`, `style.css` и `app.js` должны лежать рядом в корне репозитория.


## Обновление версии 2

В этой версии добавлены:
- Личный кабинет клиента: сохранение имени и телефона в браузере, просмотр записей, статусы, отмена и отзывы после завершённого визита.
- Отзывы и рейтинг мастеров: средняя оценка и список комментариев отображаются в каталоге.
- Карта мастеров: группировка специалистов по городам и переход к поиску города в OpenStreetMap. В демо-данных используются города, а не точные адреса мастеров.
- Статистика специалиста: количество записей по статусам, расчётный доход по завершённым визитам, рейтинг и число отзывов.
- Оплата по-прежнему только банковской картой в демонстрационном режиме; реальные платежи не обрабатываются.

### Важное ограничение демо-версии
Данные профилей, записей и отзывов хранятся в localStorage конкретного браузера. Это демонстрация интерфейса, а не полноценная авторизация с общей базой данных. Для реального запуска потребуются сервер, база данных, защищённая авторизация, точные адреса/координаты мастеров и подключение платёжного провайдера.
