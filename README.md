# BIRGA — демонстрационный веб-сервис

Адаптивный прототип сервиса поиска специалистов и онлайн-записи для Республики Ингушетия.

## Запуск
1. Скачайте ZIP и распакуйте его.
2. Откройте `index.html` в браузере.
3. Для публикации на GitHub создайте репозиторий и загрузите все файлы проекта.

Для локального запуска не нужны сервер, база данных или установка зависимостей.

## Что реализовано
- Каталог демонстрационных специалистов в Назрани, Магасе и Карабулаке.
- Категории: красота и уход, обучение, бытовые услуги и ремонт.
- Поиск по имени, специализации и услугам.
- Фильтры по городу, категории и максимальной цене; сортировка по рейтингу и цене.
- Карточки специалистов с услугами, ценами, рейтингом, отзывами и адресом.
- Выбор свободного времени и подтверждение записи.
- Сохранение демонстрационных записей в `localStorage` браузера.
- Кабинет специалиста: обзор записей, профиль и расписание.
- Адаптивная вёрстка для смартфонов и компьютеров.

## Важно: границы демонстрации
Это фронтенд-прототип для презентации идеи, а не готовая коммерческая платформа:
- данные специалистов тестовые;
- кабинет не использует регистрацию и авторизацию;
- записи сохраняются только в браузере, где их создали;
- уведомления и напоминания показаны как сценарий будущей серверной функции, автоматическая отправка не подключена;
- оплата производится на месте; онлайн-оплата не реализована;
- нет серверной базы, реальной модерации отзывов и синхронизации расписаний.

## Соответствие бизнес-плану
Первая версия — адаптивный веб-сервис. Медицинское направление не включено. Основные функции соответствуют разделам презентации: поиск и фильтры, карточка специалиста, расписание и запись, кабинет специалиста, отзывы и постепенное развитие оплаты.

## Структура
- `index.html` — страницы и разметка;
- `style.css` — оформление и адаптивность;
- `app.js` — тестовые данные и интерактивность.
