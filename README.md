# БИРГА — онлайн-запись к местным мастерам

Демо-прототип сервиса записи к мастерам в Назрани, Магасе и Карабулаке.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Для кабинета специалиста откройте `specialist.html`.

Сборка, сервер и установка зависимостей не требуются.

## Возможности прототипа

- Каталог мастеров с поиском и фильтрами по категории, городу и цене.
- Запись с выбором услуги, даты и свободного времени.
- Учёт рабочих дней и занятых временных слотов.
- Демо-оплата или оплата на месте.
- Поиск записей клиента по номеру телефона и отмена записи.
- Кабинет специалиста: подтверждение, завершение и отмена записей.
- Редактирование услуг, цен, города, рабочих дней и пароля.
- Админ-панель: список специалистов, общая таблица записей и сброс демо-данных.
- Тёмная тема и адаптивная вёрстка.

## Важно: ограничения демо-версии

Это **клиентский прототип**, а не готовая безопасная платформа для реальных клиентов. Данные хранятся в `localStorage` конкретного браузера и устройства. Чтобы клиентская и мастерская страницы видели одни данные, их нужно открыть в одном браузере на одном устройстве.

Пароли находятся в JavaScript и предназначены только для демонстрации. Не используйте реальные пароли и персональные данные. Демо-оплата не списывает деньги. Для публичного запуска потребуются сервер, база данных, серверная авторизация, безопасное хранение паролей, резервное копирование и подключение платёжного провайдера.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `birga`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через несколько минут сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/birga/`.

Файлы `index.html`, `specialist.html`, `style.css` и `app.js` должны лежать рядом в корне репозитория.
