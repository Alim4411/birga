# BIRGA — демонстрационный веб-прототип

Прототип подготовлен по бизнес-плану BIRGA для учебной презентации. Это адаптивный веб-сервис, а не готовая коммерческая платформа.

## Состав проекта — ровно 7 файлов

1. `index.html` — клиентский каталог, поиск, фильтры и онлайн-запись.
2. `specialist.html` — кабинет специалиста.
3. `admin.html` — демонстрационная панель модерации профилей и отзывов.
4. `style.css` — общий адаптивный дизайн.
5. `app.js` — демонстрационные данные, каталог и сценарий записи.
6. `specialist.js` — функции кабинета специалиста и модерации.
7. `README.md` — эта инструкция.

## Как запустить

1. Скачайте ZIP и распакуйте папку.
2. Откройте `index.html` в браузере (Chrome, Edge или Яндекс Браузер).
3. Для демонстрации откройте также `specialist.html` и `admin.html`.
4. Изменения сохраняются в локальном хранилище браузера. Для чистой демонстрации используйте кнопку сброса в панели модерации.

## Что реализовано по презентации

- Единый каталог специалистов и организаций с категориями, поиском и фильтрами по городу.
- Карточки с услугами, ценами, адресом, рейтингом, отзывами и свободными слотами.
- Сценарий записи на конкретное свободное время с подтверждением.
- Кабинет специалиста: редактирование профиля, услуг, свободных слотов, список записей и базовая статистика.
- Статусы записей: подтверждена, завершена, отменена.
- Раздел модерации профилей и отзывов.
- Первые направления: красота и уход; репетиторство и обучение; бытовые услуги и ремонт.
- Демонстрационные города: Назрань и Магас.
- Оплата исполнителю на месте. Онлайн-оплата намеренно не добавлена: согласно презентации, она рассматривается после пилота.
- Медицинское направление не включено: в презентации оно требует отдельной правовой проверки.

## Важно

В прототипе используются демонстрационные профили и данные. Сохранение работает только в том браузере и на том устройстве, где открыт сайт. Реальный сервис потребует серверной части, базы данных, регистрации и авторизации, защищённой обработки персональных данных, серверных уведомлений и полноценной модерации. Напоминания в этом MVP представлены информацией о записи; гарантированные push/SMS-уведомления потребуют серверной интеграции.

Внешние шрифты загружаются из Google Fonts; без интернета браузер использует системный шрифт.
